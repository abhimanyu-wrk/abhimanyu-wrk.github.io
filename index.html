Privacy & Transparency Notice
Browser APIs (Local Only) Browser, OS, display, hardware concurrency, device memory, and battery data are inspected locally via standard JS APIs. No persistent ID, canvas fingerprint, or audio fingerprint is generated.
External IP Lookup Disclosure Clicking scan triggers an HTTPS request from your browser to ipwho.is (with fallbacks to get.geojs.io, freeipapi.com, and api64.ipify.org), which receives your request and public IP to return approximate IP geolocation. Precise GPS requires a separate opt-in button.
WebRTC STUN Testing When initiated, WebRTC creates a temporary data-channel connection using stun:stun.l.google.com:19302 to gather ICE candidates, then closes immediately without saving or sending candidates anywhere.
Backend & Data Retention No cookies, no analytics, no localStorage, and no database persistence. In optional Node.js server mode, document headers are inspected in memory with Cookie/Authorization redacted by default and never logged or stored.
